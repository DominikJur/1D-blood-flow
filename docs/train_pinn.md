# PINN Training (scripts/train_pinn.py)

## Purpose
Train a physics-informed neural network (PINN) per topology to emulate the 1D blood
flow solver (one network per entry in scripts/topology_config.py).

## Dependencies
- deepxde, torch, numpy, pandas.
- Uses torch device = "cuda" if available (float64).

## Data Requirements
- Requires data/<topology>_blood_flow_data.csv generated by scripts/solver.py.
- If solver physics change, regenerate the CSVs before training.
- Usage: `uv run python scripts/train_pinn.py --train` (all topologies),
  `--topo y_bifurcation` (one topology), without `--train` it evaluates and renders
  the prediction GIF only.

## Normalization
Inputs:
- t_norm = t / T_out
- z_norm = z / L (per vessel)
- vessel one-hot (3 values)

Outputs:
- A_hat = A / A_scale, Q_hat = Q / Q_scale
- A_scale = max(A0_p, A0_d1, A0_d2)
- Q_scale = Q_peak

The PDE residual is computed in physical units by de-normalizing A_hat and Q_hat.

## Physics (Nonlinear Tube Law)
- Tube law: P = beta * (sqrt(A) - sqrt(A0))
- Wave speed: c = sqrt(beta / (2 * rho)) * A^(1/4)
- Riemann invariants: W1 = u + 4c, W2 = u - 4c

## Positivity Constraint
- The area output (A_hat) is strictly bounded to be positive using a `Softplus` activation. This is essential to prevent negative or zero area predictions, which would cause the 1/A and 1/sqrt(A) terms in the physical equations to explode and derail the training gradients.

## Loss Terms
Total loss = data + PDE + BC.
- Data: MSE on (A_hat, Q_hat).
- PDE: continuity and momentum residuals in physical units.
- BC:
  - Inlet: Q(t, z=0) = Q_in(t)
  - Outlet: W2 = W2_0 (non-reflective)
  - Junction: mass conservation + total pressure continuity

## Training Flow
1. Supervised pretrain on data (Adam, then L-BFGS).
2. Physics-informed fine-tuning with a custom loop (Adam).
3. L-BFGS on the combined loss (data + PDE + BC).

## Outputs
- models/<topology>_pinn.pth (PyTorch state_dict).
- gifs/<topology>_pinn_prediction.gif (prediction animation).
- logs/train_all.log (training log, gitignored).

## GPU Notes
- Uses torch.device("cuda" if available).
- All tensors are created on the selected device.
- No training is executed automatically beyond what the script runs.

## Tuning Tips
- If training is unstable, reduce learning rate or increase PDE/BC weights.
- Ensure the normalization scales match the data range.
